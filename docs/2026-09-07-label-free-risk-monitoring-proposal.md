# 研究方案：时间序列分类流的无标签风险监测

> 2026-09-08 修订：以 [完整实验协议](2026-09-08-label-free-risk-monitoring-experiment-protocol.md) 为执行依据。本文是早期构想，不能把其中的“拟议保证”视为已证明结论。确认风险超标应使用风险下界；无标签迁移条件、基线的标签预算和主数据集选择已在新协议中明确。

## 题目

**Which Shifts Actually Hurt? Fine-Grained Anytime Label-Free Risk Monitoring for Time-Series Classification Streams**

**哪些漂移真正有害？面向时间序列分类流的细粒度任意时刻无标签风险监测**

## 一句话问题定义

一个已经部署、且不在测试时更新的时间序列分类器持续接收**无标签且时间相关**的样本流。系统不把“输入分布变了”等同于故障，而是持续回答：

> 当前模型的分类风险是否已经超过允许阈值？若是，哪一类预测、哪一种运行状态、哪个局部时间段出了问题？

目标域标签在部署时不可用；源域训练集和独立带标签校准集可用。目标域的真标签只用于离线评估，绝不参与监测器训练、阈值选择或报警。

## 为什么值得做

普通漂移检测检验的是 \(P_t(X)\neq P_0(X)\)，但输入变化可以是无害的。论文监控的是分类器的实际风险：

\[
R_{t,w}(f)=\frac{1}{w}\sum_{i=t-w+1}^{t}
\mathbb{P}[f(X_i)\neq Y_i].
\]

对于每一个窗口 \(w\)，仅当有证据显示

\[
R_{t,w}(f)>R_{\mathrm{ref}}(f)+\epsilon
\]

时才触发失效报警。这把“发现数据变了”变成了“知道模型是否还可靠”。

现有无标签有害漂移检测和通用序贯监控已经覆盖了系统级报警；本项目的差异是同时处理时间依赖、无标签风险估计、细粒度定位和任意时刻误报控制。相关起点包括 [Sequential Harmful Shift Detection Without Labels](https://proceedings.neurips.cc/paper_files/paper/2024/hash/e9721921b799b6ea98d37f9e77f1a7fe-Abstract-Conference.html)、[D3M](https://papers.nips.cc/paper_files/paper/2025/hash/0bb251eba663f0345c0929f5bbbfb6dc-Abstract-Conference.html) 和 [WATCH](https://proceedings.mlr.press/v267/prinster25a.html)。

## 可防守的研究边界

论文不应声称“完全无标签下可检测任意概念漂移”。这是信息论上不可能的：若两个目标过程产生相同的 \(X\)、模型 logits 和内部特征，但标签规则不同，任何只观察这些量的算法都无法区分它们。

因此，研究对象是**可观测证据支持的有害漂移**。形式化假设为：

1. 模型失效会在预测不确定性、增强不一致性、特征支持度、模型分歧或时间动态中留下至少一项可观测信号；
2. 数据流在短窗口内满足有界依赖，例如 \(\beta\)-mixing，或者可分成近似独立的块；
3. 目标风险代理需要明确的条件稳定性或有界迁移偏差假设。源域校准和支持范围重叠本身不保证目标误差可识别；超出支持范围时可输出“不确定/无法保证”，但支持范围内也可能发生不可观测的概念漂移。

这不是软弱的限制；把“可识别漂移”和“不可识别漂移”明确分开，本身可以成为理论贡献。

## 拟议方法：Temporal Risk Evidence Monitor（TREM）

### 1. 无标签风险证据

冻结任意分类器 \(f\)，为每个流样本构造模型无关的证据向量：

\[
z_t=[H(p_t),\;m_t,\;D_{\mathrm{aug},t},\;D_{\mathrm{ens},t},\;
d_{\mathrm{support},t},\;S_{\mathrm{change},t},\;D_{\mathrm{temporal},t}].
\]

其中包括预测熵与 margin、轻量时序增强前后的预测分歧、两个异构分类器的分歧、表征空间支持度、滑动变化点分数及相邻预测的动态不一致性。主方法只需要前四项；原型距离和多分支分歧作为增强版本，避免论文绑定某一种网络结构。

在源域训练/校准流及受控漂移流上，用实际 0/1 错误监督风险代理：

\[
q_\phi(z_t)\approx\mathbb{P}[f(X_t)\neq Y_t\mid z_t].
\]

代理同时输出 epistemic uncertainty；样本离开源域证据支持集时，监测器扩大区间或拒绝给出风险结论。

### 2. 细粒度风险，而非单一总错误率

监测下列风险组：

\[
\mathcal{G}=\{\text{global},\;\widehat Y=c,\;\text{regime}=r,\;
\text{transition}=u\to v,\;\text{worst-window}\}.
\]

这里的类别风险定义为预测条件风险 \(\Pr(f(X)\neq Y\mid \widehat Y=c)\)，而不是无标签条件下无法直接识别的真类别风险 \(\Pr(f(X)\neq Y\mid Y=c)\)。状态组由无监督 regime 分割或可观测设备/主体元数据形成；转移组由连续预测或状态的切换定义。

这允许系统发现“总体风险正常，但预测为某类、某状态切换段已失效”的情况。

### 3. 时间依赖下的任意时刻上界

将流切为自适应块，按估计依赖长度计算有效样本量。对每个组 \(g\) 和窗口 \(w\)，由代理输出构造风险上界：

\[
U_{t,w,g}=\widehat R_{t,w,g}+B_{\mathrm{proxy}}+B_{\mathrm{dep}}+B_{\mathrm{seq}}.
\]

- \(B_{\mathrm{proxy}}\)：代理误差与分布外证据的不确定性；
- \(B_{\mathrm{dep}}\)：时间依赖导致的有效样本量修正；
- \(B_{\mathrm{seq}}\)：跨所有时刻、窗口和组的任意时刻校正。

上述上界是待研究的形式，不能仅按自相关估计有效样本量便声称有效。还需构造有效风险下界 L，并把参考风险的估计误差计入。若这些界在声明的假设下有效，才可研究无有害漂移时的误报控制：

\[
\Pr_{H_0}\left(\exists t,w,g: L_{t,w,g}>U_{0,g}+\epsilon\right)\leq\alpha.
\]

报警规则为 \(L_{t,w,g}>U_{0,g}+\epsilon\)。上界越过阈值仅说明无法确认安全，不足以确认有害漂移。输出分为“有证据超标”“在假设下未超标”“证据不足”三态；新实验协议给出细节。

### 4. 两个理论命题

1. **不可识别性边界检查**：构造观测等价而标签机制不同的目标流，展示无标签风险估计的限制。这一一般结论已有文献，不能单独算作原创贡献。
2. **可识别条件下的时序保证（研究目标）**：在明确的代理迁移偏差与依赖假设下，推导局部风险区间及跨时刻/组的误报控制。源域校准误差有界不自动意味着目标误差有界，证明尚未完成。

理论目标是风险上界和报警的正确性；不要承诺在完全无标签环境中恢复每个时刻的精确真实错误率。

## 实验协议

### 数据集与真实时间顺序

第一阶段选择两个任务类型明显不同的数据集：

| 任务 | 建议数据集 | 自然漂移 |
| --- | --- | --- |
| 可穿戴/活动识别 | HHAR 或 WISDM | 主体、手机/设备、采样条件与活动比例 |
| 长序列状态分类 | Sleep-EDF | 个体、夜间时段、睡眠阶段转移与信号质量 |

扩展实验加入 Opportunity 或 PAMAP2。所有评测都保留原始主体、设备和时间顺序；不允许将未来样本随机打散进校准或训练。

### 漂移类型

每个数据集都需同时包含自然切分和受控压力测试：

1. 主体/设备/日期变化；
2. 传感器缺失、噪声、幅值缩放、频带损失和采样率变化；
3. 类别先验与类别持续时长变化；
4. 状态转移规律变化；
5. 有害与无害漂移配对：输入统计变化接近，但一组明显提升模型风险，另一组不提升。

第五项是关键。它直接验证“检测风险”比“检测分布差异”更有用。

### 分类器与比较基线

主实验使用三个冻结骨干：InceptionTime/TCN、轻量 Transformer，以及一个随机特征或 MiniRocket 基线。监测器不改变主分类器参数。

基线至少包括：

1. 无监控、最大 softmax 概率、预测熵、energy 和 Mahalanobis/OOD 分数；
2. MMD/KL/变化点等输入漂移检测；
3. 无标签有害漂移检测和模型分歧基线；
4. 时间无关的在线 conformal 或 e-process 监控；
5. 仅总风险的本方法消融。

若某篇基线没有官方代码，则复现其公开算法设定，或在主表中说明不可复现原因并报告公开实现的结果。

### 指标

必须报告而非只报 AUROC：

- 风险估计 MAE、偏差和风险校准误差；
- 风险上界的经验覆盖率；
- 长时间运行下的假报警率；
- 有害漂移检测延迟和未检出率；
- 最坏滑窗风险、预测条件组风险与定位命中率；
- 对无害漂移的错误报警；
- 每个样本的吞吐、显存和额外延迟。

## 两周可行性闸门

不等理论与大规模实验完成，先做以下判定：

1. 在 HHAR/WISDM 和 Sleep-EDF 的两个时间顺序流上，使用冻结 TCN 和 Transformer；
2. 先比较 entropy、augmentation disagreement、prototype/support distance、change score 对“真实窗口风险”的相关性；
3. 构造相近幅度的有害/无害漂移配对，测试风险代理能否区分它们；
4. 与总风险阈值、MMD 变化点和时间无关校准监控比较。

继续投入的信号是：风险代理在两个数据集上稳定区分有害与无害窗口（AUROC 约 0.75 以上），风险估计与真实窗口风险有显著相关，且时间依赖修正能明显降低错误报警。若这些信号不存在，应先重新审视可观测证据假设，而不是堆叠更多网络模块。

## 主要风险与应对

| 风险 | 应对 |
| --- | --- |
| 无标签代理只能识别 OOD，不能识别真正错误 | 用有害/无害配对协议；显式报告风险校准与覆盖率，不以 OOD AUROC 代替风险估计 |
| 理论假设过强 | 将“不可识别性”写成正面贡献；为有限依赖与校准误差给出可检验的诊断 |
| 细粒度组发生多重检验误报 | 将风险组预注册，采用层次化 alpha 分配和跨组 e-value 聚合 |
| “真实”实验只靠人工扰动 | 主表优先使用主体、设备、日期和时段形成的自然漂移；人工扰动只作压力测试 |
| 贡献被认为是模块拼装 | 以“从错误代理到依赖流任意时刻风险上界”的统一估计问题为主线，实验和定理都围绕该主线组织 |

## 立即执行的选择

第一阶段优先做 **HHAR + Sleep-EDF**，固定 `TCN + Transformer` 两种骨干。先冻结分类器并建立无标签监测基线；在证据显示风险代理有效之前，不开始实现复杂理论或测试时适应。
